## 🚀 Sobre mí

Soy Frontend Developer especializado en React y TypeScript, con experiencia profesional desarrollando y modernizando aplicaciones web.

Actualmente soy responsable del frontend dentro de un equipo compuesto por desarrolladores backend, QA y Product Manager. Trabajo en la migración de código legacy, el desarrollo de nuevas funcionalidades y la construcción de un panel administrativo y una aplicación para clientes.

Participo en procesos de registro, compra y gestión de estacionamientos, integrando APIs REST y desarrollando componentes como formularios, grillas, skeletons, botones, inputs, selects predictivos y herramientas para el recorte de imágenes.
